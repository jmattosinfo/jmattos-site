01 — Sobre

Sobre mim

Minha jornada começou com uma curiosidade técnica que me levou das estruturas físicas de hardware e redes ao desenvolvimento de software. Essa base sólida em infraestrutura hoje me proporciona uma visão privilegiada para entender como as aplicações operam de forma mais eficiente.

Hoje, foco em criar soluções web completas, integrando o poder do Python e Django no backend com a interatividade do React no front. Onde vejo processos repetitivos, construo automações (RPA) para transformá-los em software escalável.

Procuro oportunidades desafiadoras para atuar como desenvolvedor, continuar evoluindo em engenharia de software e contribuir para soluções tecnológicas que geram impacto real.
